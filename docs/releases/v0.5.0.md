## What's new in 0.5.0

- **Starts faster.** The window paints in about half the code it loaded before; the other views arrive in the background, and "Starting McBot Studio…" goes away as soon as the engine is up.
- **Agents tell the truth about their files.** After a restart, a compiled agent reads Ready (or "Changed · compile"), not "Not compiled".
- **Connector sign-in says how it went:** waiting for your browser, signed in, or why it failed.
- **Know when there's a new version.** McBot Studio checks for a newer release and offers Download (Settings → About).
- **New chats start with three suggestions** that fit what the agent is for.
- The web demo no longer says its simulated Ollama isn't running.
