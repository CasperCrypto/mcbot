## What's new in 0.6.1

- **The built-in browser shows its own screen when a page won't load.** When a site doesn't answer, or your computer goes offline, the Browser view now says "Can't reach …" or "You're offline" in McBot's own look, with Try again, instead of the web engine's error page (on Windows that was Microsoft Edge's, which made it look like Edge had opened). It also checks pages you reach by clicking links inside the browser.
