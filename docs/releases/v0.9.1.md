## What's new in 0.9.1

- **One Files view for every folder.** Files and Code are now one view (⌘7): your agents' folders, the shared files and any folder you open. Drop files or whole folders in from Finder or Explorer, make new files and folders, rename (F2), move by dragging onto a folder, and delete (⌘⌫). A deleted file waits in McBot's trash for 30 days, and Undo or ⌘Z puts it back. Text and code open in the editor, Markdown reads as a page first, pictures, video, sound and drawings show as themselves, Map shows a folder as a graph, and a terminal opens right there. In an agent's own folder only its workspace takes new files; its settings are edited, never moved.
- **Ask an agent from anywhere.** The same Ask bar in Files (a file, the lines you selected, or a folder), in Knowledge → Business (a document you pick) and in Memory.
- **Drop files into Knowledge and Memory.** Anywhere on Business, a dropped file becomes a document every agent can read. On Memory, drop it on MEMORY.md or USER.md: a short text becomes memory, and a bigger file becomes a document instead.
- **Unsaved edits wait for you.** Open files and unsaved text stay while you visit another view.
- Fixed: in the Browser on Mac and Windows, the agent picker, menus and the island opened underneath the web page. They now open on top, and the page comes back where you left it.
- Fixed: dropping files from Finder or Explorer into McBot did nothing in the desktop app.
- Fixed: the Browser's passwords pop-up is frosted glass again, and a notice with Undo or Open stays long enough to use it.
