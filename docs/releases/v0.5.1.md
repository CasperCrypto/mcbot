## What's new in 0.5.1

- **19 ready-made agents** (was 6), in five groups: Everyday, Work, Create, Build and Money. Researcher, News Watcher, Social Media Manager, Code Reviewer, Web Builder, Market Analyst, Finance Modeler and more.
- **Agents come with Hermes skills.** Each card names the skills it starts with from Hermes' official library (remove any you don't want), and they install by themselves once the agent is ready.
- **8 starter teams** (was 4). New: Personal assistant, Launch team, Market desk and Knowledge base. Each member brings its own skills.
- **See everything Hermes knows.** The Skills view lists Hermes' 44 built-in skills by name, and the web demo shows the whole 141-skill library.
