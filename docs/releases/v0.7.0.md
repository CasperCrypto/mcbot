## What's new in 0.7.0

- **A new design.** Deeper blacks, hairline edges and tighter corners; flat cards, quiet controls and one soft shadow for what floats. Kinds show as a tint behind their glyph, brand logos sit on their own colour, and McBot's burger marks what McBot itself does. The dock is a quiet row of glyphs, the rail's selection slides, Home opens on today (spend, runs, tasks done) and the getting-started list shows its progress. McBot is dark, always; Settings → Appearance (or ⌘K) picks one of macOS's eight accent colours, and every open window follows at once.
- **GitHub as a tool.** Add GitHub from the tool catalog: repos, issues, pull requests and code search, on GitHub's own hosted server with your token. Your token stays in McBot; the board only names it.
- **Skills that fit.** The Skills view suggests library skills for each agent from what it is for, a starter agent's own picks first. Skill and category names read properly (Antigravity CLI, Autonomous AI agents, MLOps, MCP servers).
- **The harness doctor checks tool keys.** A tool wired to an agent without its key now shows up with Add key, before a run fails.
- **Chat apps say what they need.** The catalog reads "2 keys · api.slack.com" instead of a list of variable names.
- **Cost reads like a chart.** Every day of the last two weeks is on it, ending today, days with no spend included; agents show by name, and the view has a title like the others.
- **Runs** show tool steps the way the chat does ("Files: list directory"); the tool's own name is in the step's details.
- Fixed: a long model name pushed an agent block's model and cost out of its card.
- Fixed: the board showed through the inspector and other reading panels.
- Fixed: on a narrow window the inspector covered the Board, Layers and Hermes switch.
- Fixed: Ask McBot's request box looked like a plain browser field.
- New website sections, Ask McBot and Connect, and a proper preview card when the link is shared.
