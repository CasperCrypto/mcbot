## What's new in 0.7.0

- **Invite anyone, like a shared document.** Share makes a link that works from anywhere (through a free, no-account Cloudflare link) or only on your network. Email it from Gmail, Outlook or your mail app, copy it, or show its QR code to a phone. It opens in any browser, so nobody installs anything or makes an account.
- **Teammates and guests.** Teammates edit and run your agents with you. Guests, such as customers, get a chat with just the agents you pick and see only their own conversations; anything an agent asks to do is yours to allow. Share warns you when a guest could make an agent use files, the terminal or the computer.
- **Passwords.** Your logins and API keys in one place. Passwords are sealed with a key kept outside your McBot folder and are never shared with people you invite. In the browser, a key in the address bar fills a login on its own site, or copies it.
- **A browser that starts somewhere.** A start page with one search field, your favorites as brand tiles, what is running on this computer and the pages you visited last; a star to keep a page, and one-click Summarize, Key facts and Translate for any page.
- **Add from GitHub.** Paste or drop any GitHub link: McBot says whether it is a skill, an MCP server, a Hermes plugin or a project, and adds it to an agent, or downloads it for your agents to work on, in one click.
- **A smaller download.** The app no longer carries 69 MB of source maps.
- **Know which harness is better.** Every compile that changes the harness is kept in the board's new History, with what changed in words and how its runs went: success, cost, time and tokens per run. Pick two versions to compare them side by side, name the good ones, restore any in one step (⌘Z takes it back). ⌘K "Copy the harness as text" hands the whole graph to any AI.
- **One page per agent.** Personality, the models it thinks with (main and backups), its tools and chat apps, skills, abilities and limits are on one scrolling page: on the board when you select an agent, and beside its chat (the panel button in the chat header). New agent is now a name, what it does and a starting card; it then opens on that page.
- **Home, redone.** A large title with the day in pills (who is at work, what needs you, today's spend), one Ask box with the agent picked inside it, your agents as tiles that show what each is doing (Stop and Settings on each), then Needs you, Spent today with the last seven days, Lately and Up next. No greeting.
- **Models by name and logo.** An agent's model shows as its family's mark and the name people say (Claude Sonnet 4.5, GPT-4o mini, Qwen3 8B) on blocks, tiles, chat, Settings and Cost, so long ids no longer break the layout.
- **Thinking per agent.** Off, light, medium, deep or deepest, compiled to Hermes' reasoning effort.
- **Only the tools an agent needs.** A tool block can list just the tools it should offer (patterns work); fewer tool definitions go to the model on every message, so each message costs less.
- **A bigger app icon.** The glass burger from the website, large on a black tile, on Apple's grid for macOS and full-size for Windows and Linux.
- **A new website.** Why McBot (your agents stay yours, any model, the harness you can see), the app's chat and the harness compiling as live views, moving brand rows, a comparison and plain answers.
- **A new design.** Deeper blacks, hairline edges and tighter corners; flat cards, quiet controls and one soft shadow for what floats. Kinds show as a tint behind their glyph, brand logos sit on their own colour, and McBot's burger marks what McBot itself does. The dock is a quiet row of glyphs, the rail's selection slides, Home opens on today (spend, runs, tasks done) and the getting-started list shows its progress. McBot is dark, always; Settings → Appearance (or ⌘K) picks one of macOS's eight accent colours, and every open window follows at once.
- **GitHub as a tool.** Add GitHub from the tool catalog: repos, issues, pull requests and code search, on GitHub's own hosted server with your token. Your token stays in McBot; the board only names it.
- **Skills that fit.** The Skills view suggests library skills for each agent from what it is for, a starter agent's own picks first. Skill and category names read properly (Antigravity CLI, Autonomous AI agents, MLOps, MCP servers).
- **The harness doctor checks tool keys.** A tool wired to an agent without its key now shows up with Add key, before a run fails.
- **Chat apps say what they need.** The catalog reads "2 keys · api.slack.com" instead of a list of variable names.
- **Cost reads like a chart.** Every day of the last two weeks is on it, ending today, days with no spend included; agents show by name, and the view has a title like the others.
- **Runs** show tool steps the way the chat does ("Files: list directory"); the tool's own name is in the step's details.
- Fixed: a long model name pushed an agent block's model and cost out of its card.
- Fixed: a model wired by dragging out of an agent did not count as its model in Home and Settings.
- Fixed: a tool list set in Hermes (`tools.include` / `tools.exclude`) was dropped by McBot's next compile; it is now read back and kept.
- Security: a policy for private reports, Dependabot and CodeQL; the sample board no longer uses placeholder company names.
- Fixed: the board showed through the inspector and other reading panels.
- Fixed: on a narrow window the inspector covered the Board, Layers and Hermes switch.
- Fixed: Ask McBot's request box looked like a plain browser field.
- New website sections, Ask McBot and Connect, and a proper preview card when the link is shared.
